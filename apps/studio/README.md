# @dbz-code/studio

> DBZ Code desktop UI — built with Tauri and React.

Part of the [DBZ Code](../../README.md) monorepo.

## Development

```bash
pnpm dev        # start Vite dev server
pnpm tauri dev  # start Tauri desktop app (requires Rust)
```

## Build

```bash
pnpm build        # build for web
pnpm tauri build  # build desktop binary
```
